# Conception PCB d’un amplificateur Hi-Fi 15W

## 🧠 Description du projet
Ce projet consiste en la conception et le routage d’un circuit électronique de contrôle d’alimentation pour un amplificateur Hi-Fi 15W à tubes, réalisé sous **Altium Designer**.

---

## 🎯 Objectifs
- Réaliser la schématique électronique multi-feuilles
- Concevoir le PCB (placement et routage)
- Optimiser les pistes et l’implantation des composants
- Assurer la fiabilité du circuit d’alimentation

---

## 🛠️ Outils utilisés
- Altium Designer
- Conception schématique électronique
- Routage PCB

---

## 📌 Contenu du projet
- Schémas électroniques (6 feuilles)
- PCB layout
- Vue 3D du circuit
- Rapport technique
